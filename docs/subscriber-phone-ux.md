# Телефон в анкете подписчика

После имени бот предлагает передать свой контакт или ввести номер вручную.
Принимаются номера с кодом 998, с плюсом или без него; пробелы, скобки
и дефисы удаляются. Сохраняется только формат `+998` и девять ASCII-цифр.
Номер без кода страны, другого государства, с буквами или неверной длиной
отклоняется. Проверка формата не подтверждает существование номера.

Контакт принимается только при совпадении его `user_id` с отправителем.
Отсутствующий `user_id` также означает отказ. Ручной ввод сохраняется и
не считается доказательством владения номером. Новые признаки согласия
или верификации в базе не создаются.

Оба способа используют общий путь сохранения, очистки FSM и квалификации
реферала. Главное меню заменяет временную клавиатуру. Подписка, схема БД
и правила выдачи реферальных наград не изменены. Общая кнопка запроса
контакта в регистрации команды получает такое же уточнённое название.

Проверка: `python -m unittest discover -s tests -q`.
Тесты используют синтетические Telegram Update через Dispatcher,
временную SQLite и сессию без HTTP. Перед внедрением проверить интерфейс
в отдельном тестовом боте: ручной номер, своя кнопка контакта, чужой
контакт, ошибка и повторный ввод, возврат главного меню, реферальный путь.
Миграция не нужна. Откат: вернуть предыдущую версию приложения;
сохранённые номера остаются совместимыми.
